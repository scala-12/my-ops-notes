# Two Windows 11 Installations on One PC

Инструкция для чистой установки двух Windows 11 на один большой физический диск в режиме UEFI/GPT. Установка удалит все данные на выбранном диске. Заранее сохраните резервную копию и ключ восстановления BitLocker.

## Installation

1. Загрузитесь с установочной флешки Windows 11 в режиме **UEFI**. На экране установки нажмите `Shift+F10`, чтобы открыть командную строку. Создайте EFI-раздел вручную с помощью DiskPart. Внимательно проверьте номер диска через `list disk`: следующая команда `clean` удалит все разделы и данные на выбранном диске.

	```text
	diskpart
	list disk
	select disk N
	clean
	convert gpt
	create partition efi size=512
	format quick fs=fat32 label="System"
	exit
	```

	Замените `N` на номер целевого диска. Не продолжайте, если не уверены, что выбрали правильный диск.
2. Закройте командную строку и продолжите установку. Выберите **Выборочная установка**, укажите оставшееся нераспределённое пространство на этом диске и установите первую Windows. Не выбирайте и не форматируйте EFI-раздел.
3. В первой Windows откройте **Управление дисками** (`diskmgmt.msc`) и уменьшите её системный раздел, оставив достаточно нераспределённого места для второй Windows и общего раздела данных.
4. Снова загрузитесь с установочной флешки в режиме **UEFI**. В режиме **Выборочная установка** выберите нераспределённое пространство, подготовленное для второй системы, и установите туда вторую Windows. Не удаляйте и не форматируйте разделы первой системы или EFI-раздел.
5. Загрузитесь во вторую Windows и в **Управлении дисками** уменьшите её системный раздел. В освободившемся нераспределённом пространстве создайте раздел для общих данных и отформатируйте его, например, в NTFS. Этот раздел будет доступен обеим системам.
6. В каждой Windows откройте **Управление дисками** и назначьте букву `B:` разделу с другой Windows: в первой системе — разделу второй, во второй — разделу первой. Не меняйте букву собственного системного раздела.
7. После установки появится меню выбора ОС. Если ПК сразу загружает одну систему, проверьте в настройках UEFI порядок загрузки и выберите Windows Boot Manager. В меню `msconfig` → **Загрузка** можно изменить систему по умолчанию и время показа меню.

## OS Names

Откройте терминал или командную строку **от имени администратора** и выполните:

```bat
bcdedit /enum osloader
```

По описанию определите записи обеих систем и их идентификаторы (`{...}`). Переименуйте их, подставив соответствующие идентификаторы:

```bat
bcdedit /set {GUID-ПЕРВОЙ-WINDOWS} description "Windows 11 — основная"
bcdedit /set {GUID-ВТОРОЙ-WINDOWS} description "Windows 11 — вторая"
```

Проверьте результат: `bcdedit /enum osloader`. Не подставляйте `{current}` для второй записи: это идентификатор только запущенной сейчас Windows.

## Start last loaded Windows

Чтобы после перезагрузки автоматически запускалась Windows, выбранная при предыдущем запуске, настройте в **каждой** установленной системе задачу, которая назначает текущую Windows системой по умолчанию. Откройте командную строку от имени администратора и выполните:

```bat
schtasks /Create /TN "RememberLastWindows" /SC ONSTART /RU SYSTEM /RL HIGHEST /TR "cmd.exe /c bcdedit /set {bootmgr} default {current}" /F
```

После старта задача запомнит запущенную Windows как систему по умолчанию для следующей загрузки. Чтобы перейти в другую систему, выберите её в меню загрузки; при следующем перезапуске будет выбрана последняя запущенная система. Настройка действует для следующих загрузок.

## BAT File to Reboot into the Other Windows

Узнайте идентификатор целевой системы командой `bcdedit /enum osloader`. В следующем файле замените `{GUID-ДРУГОЙ-WINDOWS}` на её идентификатор и сохраните файл с расширением `.bat`, например `Перезагрузка-в-другую-Windows.bat`. Запустите его **от имени администратора**. Команда задаёт целевую ОС для следующей загрузки, затем компьютер перезагружается.

```bat
@echo off
set "TARGET={GUID-ДРУГОЙ-WINDOWS}"
bcdedit /bootsequence %TARGET%
if errorlevel 1 (
	echo Не удалось задать следующую систему. Проверьте GUID и права администратора.
	pause
	exit /b 1
)
shutdown /r /t 0
```
