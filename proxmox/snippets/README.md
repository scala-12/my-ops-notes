# Snippets

Сниппеты нужны для автоматизации и кастомной настройки виртуальных машин (VM) и контейнеров (LXC).

Месторасположение сниппетов можно узнать из файла `/etc/pve/storage.cfg`
В моем случае **/var/lib/vz**.
Все сниппеты должны быть в этой папке.
