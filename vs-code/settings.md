# VS Code settings

Ниже - нейтральный базовый набор настроек для повседневной работы. Настройки форматирования и отступов лучше выбирать отдельно для каждого проекта: они зависят от языка и соглашений команды.

## Basic settings

Добавьте нужные параметры в свой `settings.json`, сохранив уже существующие настройки:

```json
{
  "editor.guides.bracketPairs": "active", // Показывать направляющие для активной пары скобок
  "editor.renderWhitespace": "boundary", // Показывать пробелы и табуляции в начале и конце строки, более одного между слов
  "editor.detectIndentation": false, // Отключить автоматическое определение отступов
  "files.insertFinalNewline": true, // Добавлять перевод строки в конец файла при сохранении
  "files.trimTrailingWhitespace": true, // Удалять пробелы и табуляции в конце строк при сохранении
  "workbench.startupEditor": "none", // Не открывать редактор приветствия при запуске
  "git.autofetch": true // Автоматически обновлять сведения об удалённых ветках Git
}
```

`editor.formatOnSave`, размер отступа и правила импорта добавляйте в проект только после выбора форматтера и соглашений команды. Например, `"editor.formatOnSave": true` удобно включать, когда в проекте настроен нужный форматтер; без него VS Code может не форматировать файл или предложить выбрать форматтер.

## Workspace settings

Создайте `.vscode/settings.json` в корне проекта и добавьте только согласованные командой параметры. Например, для проекта с отступами в два пробела и настроенным форматтером:

```json
{
  "editor.tabSize": 2, // Использовать отступ в два пробела
  "editor.insertSpaces": true, // Вставлять пробелы вместо символа табуляции
  "editor.formatOnSave": true // Форматировать файл при сохранении настроенным форматтером
}
```

Это пример, а не универсальное правило: используйте значения, соответствующие `.editorconfig`, конфигурации форматтера и языку проекта. Если проект уже содержит `.editorconfig` или настройки форматтера, предпочтительно следовать им, а не дублировать правила в VS Code.

## Proxy

### Check system proxy first

VS Code использует сетевые настройки Chromium и обычно автоматически подхватывает системные настройки прокси Windows. Если прокси уже настроен администратором, сначала перезапустите VS Code и проверьте подключение к Marketplace или обновления.

### Set proxy

Если системная настройка не сработала:

1. Откройте настройки: `Ctrl+,`.
1. Найдите `http.proxy` и укажите адрес, предоставленный администратором, например `http://proxy.example.com:8080`.
1. Либо откройте JSON настроек через кнопку `{}` и добавьте:

   ```json
   {
     "http.proxy": "http://proxy.example.com:8080", // Адрес и порт прокси-сервера; замените на выданные администратором
     "http.proxyStrictSSL": true // Проверять сертификаты TLS/SSL при подключении через прокси
   }
   ```

   Замените адрес и порт на параметры вашей сети. Не указывайте логин и пароль прямо в URL или файле настроек. Для прокси с аутентификацией VS Code может показать диалог входа.

1. Перезапустите VS Code и проверьте Marketplace. Если прокси персональный, храните эти параметры в пользовательских настройках, а не в `.vscode/settings.json`.

Параметр `http.proxy` полезен прежде всего для расширений и CLI, например при установке расширения командой `code --install-extension`. Встроенные сетевые функции редактора обычно используют системный прокси.

### If connection failure

- Проверьте адрес, порт и тип прокси у администратора сети. Для прокси с аутентификацией уточните поддерживаемый способ входа; аутентификация SOCKS5 в VS Code не поддерживается.
- Если корпоративный прокси проверяет HTTPS-соединения, установите его корневой сертификат в доверенное хранилище Windows по инструкции администратора. Оставьте `http.proxyStrictSSL` включённым.
- Не отключайте проверку сертификатов через `"http.proxyStrictSSL": false`: это снижает безопасность соединения и не должно быть обычным способом исправления проблем.
- Настройки прокси могут не применяться к отдельным расширениям: некоторые расширения используют собственные сетевые механизмы.

Официальная документация: [Network Connections in Visual Studio Code](https://code.visualstudio.com/docs/setup/network).
