# Snippets

Сниппеты нужны для автоматизации и кастомной настройки виртуальных машин (VM) и контейнеров (LXC).

Месторасположение сниппетов можно узнать из файла `/etc/pve/storage.cfg` или в настройках **Datacenter > Storage** - у соответствующего диска _Content_ будет содержать _Snippets_.
В моем случае **/var/lib/vz**.
Все сниппеты должны быть в этой папке.

## Памятка

1. Установить права на исполнение для созданного сниппета: `chmod +x`
1. <span id="attach-script">Привязать скрипт к контейнеру/VM</span>.
   К примеру, `qm set 101 --hookscript local:snippets/block_together.pl`
