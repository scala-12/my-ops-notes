# Post install settings

## Drivers

*Установить драйверы в правильном порядке и без подключения к интернету.*

| Драйвер | Примечание |
| --- | --- |
| Чипсет материнской платы | С сайта AMD или Intel либо производителя платы. |
| Видеокарта | Официальный драйвер NVIDIA, AMD или Intel |
| Сетевой адаптер и Wi-Fi | Если Windows установила нерабочий или устаревший драйвер |
| Аудиодрайвер | Если нужны специальные функции или стандартный драйвер работает неправильно |

После установки ключевых драйверов перезагрузите компьютер.

### 📁 Explorer

#### Общие настройки

`Просмотреть` > `Область сведений` > ✅. Включить `Сведения` в правом верхнем углу.

#### Параметры папок

Открыть Проводник, `Вид` → `Показать`.

| Путь | Параметр | Значение |
| --- | --- | --- |
| `Общие` | Открыть проводник для | `Этот компьютер` |
| `Общие` | Конфиденциальность | Отключить все + `Очистить` |
| `Вид` > `Дополнительные параметры` | Использовать флажки для выбора элементов | ✅ |
| `Вид` > `Дополнительные параметры` | Показывать библиотеки | ✅ |
| `Вид` > `Дополнительные параметры` | Скрывать расширения для зарегистрированных типов данных | ❌ |
| `Вид` > `Дополнительные параметры` | Скрытые файлы и папки | Показывать скрытые файлы, папки и диски |
